Pipeline lab: six stages, one instruction per clock

Load a program, press Step, and watch each instruction move FETCH1 → FETCH2 → DECODE → EXECUTE → MEMORY → WRITEBACK. This page runs the same cycle-exact model the SystemVerilog in src/ is tested against.
